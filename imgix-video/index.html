Imgix video

Video

Demos of Imgix video delivery and transformations, all using the same source file from Imgix Video API.

Demo 1

Base video

The source MP4 served as-is — no Imgix parameters applied.

https://coloradopremium.imgix.net/video/25-cpr-42172_colorado_premium_meats_30sec%20(1080p).mp4

Demo 2

Auto-optimized MP4

fm=mp4 re-encodes with H.264 and automatic bitrate selection. video-aq=enhanced runs VMAF analysis first to pick the smallest bitrate that still hits perceptual quality — typically 15–60% bandwidth savings per the Video API overview.

?fm=mp4&video-aq=enhanced

Demo 3

Manual quality (q=33)

q sets output quality directly (default is 75). Here it’s set deliberately low so compression artifacts are easy to spot — contrast with Demo 2’s automatic VMAF-based approach.

?fm=mp4&q=33

Demo 4

Slow motion (video-speed=0.5)

Half-speed playback via video-speed. Values below 1.0 enable frame interpolation by default, so motion stays smooth instead of stuttering like a native player rate change. Audio pitch is corrected automatically.

?fm=mp4&video-speed=0.5

Demo 5

Video preview

video-preview=true uses AI to pick key segments and stitch them into a short highlight reel. This build is ~5 seconds long with ~1-second segments (video-preview-duration=5, video-preview-segment-duration=1). First render may return 423 until processing finishes.

?fm=mp4&video-preview=true&video-preview-duration=5&video-preview-segment-duration=1

Demo 6

Generated subtitles

video-generate-subtitles=true transcribes the audio with AI. For a native <video> player, request a sidecar WebVTT file with fm=vtt and load it via a <track> element. Turn on CC in the player controls to see captions. First VTT request may return 423 until transcription finishes.

video: ?fm=mp4
track: ?fm=vtt&video-generate-subtitles=true

Demo 7

Clip (10s–15s)

Clip parameters extract a segment of the source. video-clip-start=10 and video-clip-end=15 trim to a 5-second clip from the middle of the spot.

?fm=mp4&video-clip-start=10&video-clip-end=15

Demo 8

Video filter (muted)

video-filter applies a named color grade. muted desaturates and crushes shadows for a documentary / cinematic look.

?fm=mp4&video-filter=muted

Other presets

  • boost Punchy and vivid — richer color, higher contrast. Good for social and marketing clips.
  • contrast Crisper tonal separation — adds definition to flat footage.
  • darken Lowers exposure — useful for dialing back a hot or overexposed shot.
  • lighten Raises exposure — opens up dim or underexposed footage.
  • greyscale Fully desaturated black-and-white (grayscale also works).
  • negative Inverts all color values — photo-negative effect.
Demo 9

Size to square

Size to 720×720. fit=crop center-crops; fit=smart-crop AI subject-tracks so the important content stays in frame.

Demo 10

Fill square → HD

Take a center square from the source (rect), then fit=fill pads it to standard HD (1920×1080) with fill=blur on the sides — landscape canvas, square subject.

?fm=mp4&rect=center,middle,1080,1080&w=1920&h=1080&fit=fill&fill=blur&fill-darken=20

Demo 11

Spritesheet

fm=spritesheet returns a single image grid of frames sampled from the video. video-spritesheet-interval=auto picks a sensible sampling rate from the duration. Pair with fm=vtt for player seek-bar previews.

?fm=spritesheet&video-spritesheet-interval=auto

Demo 12

Text overlays

txt-* composites text onto video frames — same params as the Rendering API. Up to 10 layers via txt[N]. This demo stacks “Hello” and “World” as two layers with video-txt-transition=slideup on entry.

?fm=mp4&txt=Hello&txt-size=64&txt-color=FFFFFF&txt-align=center,middle&txt-y=-40&video-txt-transition=slideup&txt[1]=World&txt-size[1]=48&txt-color[1]=FFD700&txt-align[1]=center,middle&txt-y[1]=40&video-txt-transition[1]=slideup

Demo 13

VFX bloom

Video VFX are GPU cinematic effects (0–100 intensity). video-vfx-bloom=80 adds a strong dreamy glow around highlights. Effects stack in a fixed order and run after color grade, before overlays.

?fm=mp4&video-vfx-bloom=80

Other effects

  • video-vfx-vignette Radial corner darkening that pulls focus to the center of the frame.
  • video-vfx-film-grain Analog film grain texture for a more tactile, vintage look.
  • video-vfx-halation 35mm-style glow bleed around bright highlights.
  • video-vfx-chromatic-aberration RGB channel split for a glitchy / music-video edge.

Compose order when stacked: chromatic aberration → film grain → bloom → halation → vignette. Each accepts 0–100 intensity.

Demo 14

Watermark

The mark parameter overlays an image on the video. mark takes a URL-encoded full image URL (same Imgix source works). mark-align=center,middle centers it; mark-w sets the width.

?fm=mp4&mark=https%3A%2F%2Fcoloradopremium.imgix.net%2F2026%2F06%2FoW8iUMpu-immersv.png&mark-align=center,middle&mark-w=480
